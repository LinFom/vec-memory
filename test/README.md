# memory-vec · 测试纪律（单一来源）

> 全套件通用纪律的唯一出处。各测试文件**不手抄全文**，只留一行指引指向这里
> —— 纪律和白名单一样需要单一来源，手抄必分叉。
> 项目级口径（"测试要覆盖到'不是'一个代表性字段"、"活数据不能用来测确定性"等）
> 见根目录 `CONTEXT.md`；本文件只收**测试代码层**的纪律。

## 纪律 1 · 子串断言必须圈定范围

任何 `includes()` / `match()` / 正则断言，都要**显式圈定被查对象**（只查出境记录、
只查指定字段），不许对"整个序列化产物"做裸子串匹配。

- **事故**（`test/judge.mjs`，0037 轮）：用 `JSON.stringify(prompt).includes('self')`
  断言 "self 不在出境白名单里"，结果命中的是 system 提示里的英文单词
  "it**self**" —— 断言虚假失败，实现其实是好的。
- **为什么是同族纪律**：出境白名单"精确匹配、不用宽网"防的是**误伤内容**，
  本条防的是**误伤断言**——两者都是"匹配范围必须是显式圈定的封闭集合"。
- **正确姿势**：`JSON.stringify(buildOutboundRecord(...)).includes('self')`
  （对象小且封闭）；或按字段断言（`'self' in rec`）。

## 纪律 2 · 断言 helper：**已收敛为共享模块**（2026-10-11 落地 C）

**现行**：`ok()` 断言 helper 只有**一份实现** —— `test/lib/_helpers.mjs`（导出 `ok` 与
`tally`）。任何需要断言的测试文件 `import { ok, tally } from './lib/_helpers.mjs'`
（当前 16 份，含守卫自己），收尾读 `tally.pass` / `tally.fail`。
**"行为一致"从此由构造保证，不再靠比对**。

- **为什么放 `lib/` 子目录**：`npm test` 的 glob 是 `test/*.mjs`（不递归）。放 `test/` 根下
  会被 `node --test` 当成"没有任何子测试的测试文件"收进结果计数（实测多一条
  `ok - test\_helpers.mjs`，总数虚高）。子目录即天然排除，不必改 glob / 加白名单。

## 运行方式

```bash
node test/<name>.mjs                    # 纯离线：selftest / normalizer / facts / factstore / extract / rank / panelcheck / judge / helpers-guard
node test/<name>.mjs                    # 自带假端点、也是纯离线：index-batch（真服务 + 真 HTTP + 临时根，不联网）
node test/<name>.mjs <宿主根目录>       # 需要真实存档：graph / dryrun / edges / realloop
```

> **教训：断言一个"两种情形共享的词"时，它分不开两种情形。**）；C2 = **该变异不可达**

> 7 处整表替换都作废索引 ⇒ 那一行是**纵深防御**，删掉不改变任何可观测行为）。
> ⇒ C2 的处理方式**不是**"把断言加粗到能测它"（测不到），而是**登记成对照组 + 写进源码注释**，
> 记录"这条断言**测不到**这一行"这个事实本身 —— 免得下次有人看到"删了也全绿"又去加粗一个测不到的地方。
>
> ⚠️ **假通过第三次**（前两次在 `ADR-0031`/`ADR-0032`），本次三处**形态各不相同**：
> ① `|| true` ⇒ 恒真；② `set.has('独角兽')` ⇒ 恒**假**（`tokenize` 对汉字只产**单字 + 相邻 bigram**，
> 没有三字词；**恒假比恒真更危险，它在指控没坏的东西**）；③ `searchText` 初稿**自己跟自己比**
> （`topicOverlap(text, [qInfo])`）⇒ 分数恒定、`matched` 恒空、**不报错且数字看着还挺合理**。
> ⇒ 纪律补一条：**写断言时先问"这个断言可能为假吗"** —— 不能为假就是没信息量（恒真），
