# 三维关系星图：设计、使用与验收

日期：2026-11-05。版本：0.33.0。

## 使用

在控制台选择“关系星图”。鼠标拖动旋转，右键平移，滚轮缩放；单击点亮直接邻居并打开来源侧栏，双击或点击“进入局部”飞近目标。“点亮两层关系”扩展邻域，“返回全景”恢复。放大画布不改变其他控制台页面。

默认显示当前空间全部登记人物及实际渠道，互动窗口为最近90天。顶部可选择全部历史、自定日期、渠道、关系层及星点大小依据。金色为渠道，蓝白为人物，紫色为展开的记忆。远景压低弱连线密度，缩近增加细节；选中时显示完整直接邻接。远景的文字数量限制不裁剪后台人物数据。

“人物＋渠道”适合看归属和桥梁人物；“全部记忆星海”增加事实、档案、场景条目及事件。也可在侧栏按需展开相关记忆，不把每条原始聊天变成星点。被人工隐藏的条目不展示。

勾选其他空间会联合投影，侧栏保留原空间。空间数据没有合并。只有管理员核对的“平台＋稳定ID”才跨空间去重：侧栏“核对跨空间平台身份”填写平台及精确账号/渠道ID。撤销登记后再次查询恢复独立节点。裸数字、相同昵称和相似名字不会跨空间自动合并。空间内已确认的账号绑定仍复用现有身份管理。

关系侧栏可看表达者、时间、渠道、原话，确认候选、纠正或撤回。维护前先显示直接影响范围；原话保留。也能新增明确的人工关系声明，不把人工输入冒充历史证据。

## 关系的含义

| 层 | 数据依据 | 不代表什么 |
|---|---|---|
| 渠道出现 | 用户曾在该渠道提交实际消息 | 不是当前成员名单 |
| 真实互动 | 结构化 @，或同渠道精确 messageId 回复 | 不把同时发言当互动，不计算亲密度 |
| 身份关系 | 明确陈述，保留表达者和原话，自动结果先候选 | 不因互动多就断言朋友 |
| 明确态度 | 明确说出的喜欢、信任等，单独分层 | 不根据语气猜情绪 |

互动有方向，选中连线显示箭头；侧栏也用“来源人物 → 目标人物”表示方向。同一条消息同时 @ 和回复同一人，互动总数只算一次。回复目标晚到后可解析，跨渠道或不存在的引用保持未解析。没有结构化 @ 或回复的旧历史不会补造互动。

时间筛选作用于互动与渠道活动，显式关系不因超过90天消失。索引按天聚合，边界日期使用该日聚合计数，不能用来做秒级活动审计。星点连接数以当前可见关系的不同邻居计数；活跃度是窗口内投影活动量，不是真实性评分。

自动提取只使用登记账号ID和原话连续引用，保留原表达者；歧义、否认与不同说法作为候选，不自动覆盖。当前版本把同一关系的明确肯定/否认标为冲突，展示不同说法及其来源，由人确认；没有自动裁定哪种说法为真，也没有语义冲突裁判。内容相似另设开关，默认关闭；按档案关键词 Jaccard 相似度产生稀疏连线，标明 keyword-jaccard，不代表相识、关系事实或向量语义推断。

同一对人物、同类关系、同一表达者的重复陈述合并到一个候选，增加证据而非增加“可信分”。人工修订保留历史和来源证据；被处理的旧证据重放不会复活原版本。新的独立证据可形成新候选，不覆盖人工决定。只能证明直接来源依赖，无法证明语义关联的旧记录仍需人工核对。

## 数据与任务设计

- `src/core/relationship-graph.mjs`：空间独立的可重建关系投影和持久修订日志。`input/relationship-index.json` 保存源日志末尾哈希与处理位置；重开页面复用投影，新消息只增量聚合。原始消息日志仍是事实来源，派生缓存损坏可重建。
- `input/relationships.jsonl`：使用现有 `DurableLog` 的幂等、哈希链与 fsync。关系修订校验预览令牌及版本，拒绝过期页面写入。备份恢复审计包含关系与身份核对日志。
- `input/graph-identities.jsonl`：管理员核对的平台身份；`graph-union.mjs` 只做视图并集，不改记忆、身份映射和共享授权。
- 正常整理复用已有模型请求，额外提取 `relations`。重试复用冻结的模型输出，按原始消息ID重新取证；证据缺失会失败，不静默推进。
- 历史回填必须显式指定场合与时间，先预览消息量和批数。50条一批，按持久游标运行；暂停在当前批提交后生效，重启保留暂停状态。模型失败保留进度，可续跑。验收没有触发生产模型历史扫描。
- `web/galaxy-renderer.mjs`：Three.js WebGL、批量 Points/LineSegments、轨道控制、确定性三维渠道星团布局及跨渠道加权桥接。不为每个节点创建独立网格，不运行每帧全图力学求解。
- 图形依赖随 `web/vendor/three/` 本地打包，包含 MIT 许可证，不请求 CDN。WebGL不可用明确报错。其他页面与本机免管理员凭据模式保留。

项目凭据仍需空间授权，并给定原场合；不能使用管理修订、身份核对、全场合记忆展开或历史回填。联合查询在返回前重新检查共享授权。无凭据管理仅限既有回环模式；错误凭据不会被降格为免凭据。

## HTTP扩展

均为 `POST /api/v1/spaces/{spaceId}/…`，详见 OpenAPI。

| 入口 | 行为 |
|---|---|
| `graph` | `from/to/sharedSpaceIds/scope/includeMemories`，返回完整节点、边、原空间与索引状态 |
| `graph-evidence` | `ids` 最多30个；逐条按场合过滤原话 |
| `graph-memories` | 管理端按 `actorIds` 或 `scope` 展开记忆 |
| `relationships` | `create/preview/confirm/correct/retract`，变更提供 operationId，已有记录需 expectedRev/previewToken |
| `graph-identity` | 管理员确认或撤销 nodeId 的 platform/stableId |
| `relation-backfill` | `preview/start/pause/resume`，任务通过既有 jobs 接口查询 |

## 本机验收记录

合成库：10,000节点、50,000输入边（过滤16条自环后49,984条），1600×1000 Edge，RTX4060 Laptop / D3D11。初次加载约0.7–0.9秒，稳定采样约120 FPS，页面JS堆约24–34MB；搜索、聚焦、回全景正常，无浏览器错误。这是该机器的测量，不是跨硬件保证。

实际QQA网页在同一安装的Electron中，以独立临时配置、离屏窗口加载3210真实页面及8091内嵌管理页：WebGL成功，RTX4060 / D3D11，约60 FPS。没有重启聊天宿主或伪造聊天。沿用现有身份映射后主空间3114节点、15472条关系；不同时间新消息会改变计数。私有验收截图仅留本机，不进入公开包。

回归：最终完整本地套件444项通过。首次失败是新测试未登记到 helper 守卫；登记理由后守卫通过。关系模块与协议测试覆盖有向互动、引用晚到、作用域、身份核对并集、重复证据、人工撤回、暂停/重启/续跑。修改整理与展开后追加针对性回归通过69项。公开仓库的46项服务/关系测试通过，QQ适配器12项通过、4项因该 checkout 无宿主而跳过；本机实际QQ嵌入已另行验证。完整结果见本机实施记录。

参考： [Three.js官方文档](https://threejs.org/docs/)、[3d-force-graph](https://github.com/vasturiano/3d-force-graph)。这里借鉴其三维浏览交互，实际采用批量绘图与确定性布局。
