# 通用记忆互操作与检索重排 — 决策地图（2026-11-06）

> 本文件是**对外规格快照**：记录本次 effort 的目的地、边界、切片与依赖，不随执行状态变化。
> 工单的认领、评论与结论维护在本地 Markdown tracker，不进本仓库（本仓库忽略 `.scratch/`）。
> 分支：`feat/memory-interop-rerank`，基线 `main @ c05e79f`。

## Destination

vec-memory 成为与 Agent 框架无关的**通用记忆能力服务**：

- 任意第三方 Agent 的记忆产物，都能经一套**与具体产品无关**的契约导入；
- 某个分享型整合包只是**第一个导入样例**，不是依赖、不是协议的一部分；
- 检索重排是**可开关、可降级**的检索增强，不改变落盘数据；
- 人格、情绪、念想、联想属于 Agent 侧，由接入方消费记忆产物实现，服务不承载。

走完的标志：另一个与 QQ 无关的项目照文档接上记忆能力，且 `src/core/` 与对外协议中不含任何整合包专有概念。

| 粒度 | 六张纵向切片 + 一张经确认的增量切片（07），阻塞边只保留真前置 | 每张端到端可验证，单个上下文窗口装得下；07 承接三项无票可装的记忆组织缺口 |
| 数据边界 | 只导文本与元数据，**绝不导入第三方 embedding 向量**；gist 只留派生摘要 + 回指 | 第三方向量无来源身份、维度不符会静默跳过；复制原文会破坏单一事实源 |

## 硬约束

- **专有名词不进核心**：契约字段、错误码、`src/core/` 不出现任何具体 Agent 项目名。
- **不跨层混排**：三种分数不可比；重排只在同类候选内部进行，不把事件 / 档案 / 文档混进一个数组排序。
- **默认关闭**：新特性关闭时响应必须与历史评测基线逐字可比，`externalModelRequests` 保持 0。
- **不触发重建**：重排不写 `meta`、不改 `sourceHash`、不进 `encodingIdentity`；导入不写 `vector-active.json` 指针。
- **失败降级**：超时 / 条数不符 / 非 JSON 时保留原顺序并回报稳定 `degraded` 码，不抛 5xx，也不退回关键词支路（语义不同）。
- **运行态不导入**：人格、情绪、睡眠、守则等 Agent 运行态不属于记忆服务的数据。
- **不建第二套事实库**：事件淘汰只留同一条记录上的派生摘要 + `evidenceIds` 回指，不新建文件、不复制原文。
