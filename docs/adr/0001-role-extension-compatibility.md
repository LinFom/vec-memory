# 角色扩展保持通用记忆的兼容性

溟月的心可以为角色体验附加可选元数据。同一份通用数据、同一个普通调用在相同运行条件下，应与扩展存在与否无关，包括原话、来源、权限、召回结果与排序、写入去重与重试语义。显式使用角色能力的调用可以消费扩展数据。

普通记忆备份可独立恢复和使用。搬迁角色时可选择携带扩展数据；只恢复通用记忆仍应能正常使用既有接口。通用记录与扩展的关联不可授予额外的来源访问权限。

把扩展字段直接混入现有写入请求会影响部分写入的请求指纹和幂等判定。此决定约束可观察行为及备份可移植性，扩展数据的物理位置和接口仍由后续设计确定。

## 待办与角色状态的归属

明确约定、且需要获准的其他项目接手的事项，可独立记录为通用待办；约定真有其事由原话支持，是否完成由待办状态记录。角色对这件事的惦记属于角色扩展。

心情和精力可随同一角色延续到其他会话，只影响语气与节奏。具体心事、念想正文与触发它们的聊天来源，仍受原有会话可见性与权限约束。

## 角色身份与印象

主观印象归属角色身份。新建角色时独立积累印象，可按权限使用通用记忆。沿用旧角色身份时接续该身份已有的印象及其来源。切换模型或接入项目本身不决定角色身份，也不扩大来源访问权限。

## 主观印象与通用记忆

角色可主动写入自己的理解，主观印象默认随角色身份保存。有原始证据支撑、适用范围明确的陈述可由 AI 写为通用记忆，保留出处及适用范围。同一证据被多次回忆或转述，不增加独立证据数量。

## 状态变化、纠正与历史

同一人、同一属性和适用范围内，明确的新状态用于回答现状。旧状态继续用于历史查询，并保留原始证据。分别记录陈述时间与已知生效时间，变更日期未知时只说明两次陈述各自发生的时间。人在某地与居住在某地是两种陈述，不能互相替代。

明确纠正针对所纠正的结论及其依赖项。被纠正的结论停止参与事实召回，原话仍可在权限与保留规则允许时作为更正历史核查。权限变化在读取时生效。权重只比较当前有资格使用的候选；低权重可作为回收可重建派生印象的依据，历史事实与证据的保留由它们自己的规则决定。

首版验收覆盖现状查询、带出处的历史查询、缺少确切变更日期、仅报告当前位置、明确否认曾经居住、权限撤销后无法通过角色扩展间接引用来源。用旧库副本验证，缺少时间标记的旧记录按已有证据解释，避免凭导入时间编造历史。

### 首版实现边界

事实槽已经追加保留修订版本，普通查询目前读取按既有规则选出的版本。首版用独立的时间查询入口区分现状与历史。调用方显式登记有原始消息支撑的状态和纠正；历史修订与原话仍可供回看和日后补录，首版不从旧文本自动推断状态。沿用现有普通召回、写入和备份契约；通用历史查询不依赖角色插件。修订的落盘时间仅用于审计，不能代替事情发生或状态生效的时间。
